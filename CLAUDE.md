# CCAR-F Learning Project

This repo is Naimal's hands-on prep for the Claude Certified Architect –
Foundations (CCAR-F) exam. See `src/ccar_f/moduleN/README.md` for
concept notes per module.

## Rules

- **LinkedIn post after each module:** After a module (Module 0, Module 1, ...)
  is completed, draft a short LinkedIn post summarizing what was built/learned
  in that module, before moving on to the next module. Base it on that
  module's README and actual run output — don't fabricate results not
  actually produced. Give the draft directly in the chat reply — do NOT
  create a file for it.
